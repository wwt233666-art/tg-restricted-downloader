# Telegram 受限内容下载器

绕过 Telegram 频道「禁止转发/保存」限制，将图片、视频、文件下载到本地。

## 功能

- 绕过频道管理员设置的保存/转发限制
- 按日期范围批量下载
- 私密频道 ID 下载
- 文件头魔数自动识别格式（.bin 自动纠正为正确格式）
- 多账户切换
- 一键环境安装

## 快速开始

### 1. 安装环境

右键 `安装环境.ps1` → 使用 PowerShell 运行，自动检测 Python 并安装依赖。

### 2. 配置代理（国内用户）

用记事本打开 `tg_downloader.py`，找到代理配置：

```python
USE_PROXY = True
PROXY = ("socks5", "127.0.0.1", 7890)   # 改为你的代理端口
```

| 代理软件 | 默认端口 |
|---------|--------|
| Clash Verge | socks5://127.0.0.1:7890 |
| V2RayN | socks5://127.0.0.1:10808 |
| Shadowsocks | socks5://127.0.0.1:1080 |

### 3. 启动

双击 `启动.bat`

## 使用方式

| 方式 | 输入 |
|------|------|
| 单条下载 | `https://t.me/频道名/消息ID` |
| 批量下载 | `@频道名 from 2025-06-01 to 2025-06-30` |
| 私密频道 | `-100频道ID from 2025-06-01` |

## 命令

| 命令 | 功能 |
|------|------|
| `/list` | 列出所有已加入的频道 |
| `/search 关键词` | 搜索频道 |
| `/logout` | 登出切换账户 |
| `/quit` | 退出 |

## 原理

通过 MTProto 协议以用户身份直连 Telegram 服务器，绕过客户端层面的限制。Telegram 的「禁止保存」是客户端检查，服务器端数据仍可访问。
