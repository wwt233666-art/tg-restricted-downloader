================================================================
  Telegram 受限内容下载器 — 使用指南
================================================================

【 程序功能 】
  绕过 Telegram 频道管理员设置的「禁止转发/保存」限制，
  将频道中的图片、视频、GIF、文件等媒体下载到本地。

【 运行原理 】
  通过 MTProto 协议以你的用户身份直连 Telegram 服务器，
  绕过客户端层面的限制，直接获取文件原始数据。

  支持: 图片、视频、GIF、文件、语音、网页预览中的媒体
  限制: 只能下载你已加入的频道/群组内容
  安全: 所有数据仅保存在本地，不上传任何服务器


================================================================
  第一步：安装环境（仅首次需要）
================================================================

  右键点击「安装环境.ps1」→ 选择「使用 PowerShell 运行」

  脚本会自动完成:
    1. 检测 Python 是否已安装
    2. 安装 telethon、tqdm、python-socks 依赖包
    3. 验证所有依赖就绪

  如果提示"未找到 Python"，请:
    1. 浏览器打开 https://www.python.org/downloads/
    2. 下载安装包，安装时务必勾选 [Add Python to PATH]
    3. 重新运行安装环境.ps1


================================================================
  第二步：配置代理（国内用户必须）
================================================================

  用记事本打开 tg_downloader.py，找到代理配置部分:

    USE_PROXY = False
    PROXY = ("socks5", "127.0.0.1", 7890)

  改为你的代理配置，例如:

    USE_PROXY = True
    PROXY = ("socks5", "127.0.0.1", 7890)   ← Clash 默认端口

  常见代理端口:
    Clash Verge   → socks5 127.0.0.1 7890
    V2RayN        → socks5 127.0.0.1 10808
    Shadowsocks   → socks5 127.0.0.1 1080
    HTTP 代理     → http   127.0.0.1 7890

  如何查看代理端口?
    打开你的代理软件的设置页面，找到「端口」或「Socks5 端口」


================================================================
  第三步：启动程序
================================================================

  双击「启动.bat」，看到菜单:

    1. 启动下载器（含使用指南）
    2. 快速启动（跳过指南）
    3. 查看频道列表
    4. 只看私密频道
    5. 切换/新建账户
    6. 登出账户

  首次使用请选 1，会显示完整操作说明。


================================================================
  第四步：登录 Telegram
================================================================

  首次运行会要求:
    1. 输入手机号（格式: +8613800138000）
    2. 输入 Telegram 发来的验证码
    3. 如有两步验证，输入密码

  登录成功后，session 保存在本地，以后不需要重新登录。


================================================================
  日常使用
================================================================

  【方式一】单条下载 — 粘贴消息链接
    输入: https://t.me/频道名/消息ID
    获取: 手机 App 长按消息 → 复制链接

  【方式二】批量下载 — 频道名 + 日期
    输入: @频道名 from 2025-06-01 to 2025-06-30
    日期格式: 2025-06-01 / 2025/06/01 / 20250601

  【方式三】私密频道下载 — 频道ID
    先输入 /list 找到频道ID
    输入: -1001234567890 from 2025-06-01 to 2025-06-30

  【辅助命令】
    /list      列出所有已加入的频道/群组
    /search 关键词  按名称搜索频道
    /logout    登出当前账户
    /quit      退出程序


================================================================
  文件保存位置
================================================================

  下载的文件保存在本文件夹下的 downloads 目录中。


================================================================
  常见问题
================================================================

  Q: 受限频道无法复制消息链接怎么办？
  A: 用方式二的日期批量下载代替。

  Q: 去哪里找频道用户名？
  A: 用 /list 列出所有频道，或用 /search 搜索。

  Q: 如何切换账户？
  A: 交互模式输入 /logout，下次运行登录新手机号。

  Q: 代理连不上？
  A: 检查 tg_downloader.py 中的 PROXY 配置是否正确。
     确认代理软件已开启，端口号正确。

  Q: 提示 "Connection to Telegram failed"？
  A: 1) 确认代理已开启  2) 确认端口正确  3) 尝试切换 socks5/http

  Q: 下载的文件是 .bin 格式？
  A: 程序会自动读取文件头魔数，检测真实格式并改名。
     无需手动操作。如看到 [FIX] 提示即表示自动纠正完成。
